# BudgetBuddy 💜

A full-stack personal budget planning and expense management platform for students.

## Planned features
- Registration, login and JWT authentication
- Expense and income tracking
- Monthly and category-wise budgets
- Savings goals and notifications
- Analytics dashboard and PDF/Excel reports

## Tech stack
React + Vite + Tailwind CSS | Python + Django REST Framework + SimpleJWT | SQLite (local) / PostgreSQL (production)

## Milestones
1. Project setup, database design, authentication and frontend skeleton (weeks 1–2)
2. Expenses, income and budgets (weeks 3–4)
3. Savings goals, notifications, analytics APIs and reports (weeks 5–6)
4. Dashboard, testing and deployment (weeks 7–8)

## Getting started
Install Git, VS Code, Node.js LTS and Python 3. Then follow `docs/SETUP.md`.
